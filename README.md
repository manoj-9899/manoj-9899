## Selected projects

### 🔐 [SIH-26237 — Post-Quantum Document Provenance](https://github.com/manoj-9899/sih-26237)
A browser-based prototype exploring multi-recipient encrypted document distribution, decryption-time forensic watermarking, signed provenance events, and a local tamper-evident ledger. The implementation uses ML-KEM-768, ML-DSA-65, AES-256-GCM, and SHA-256.  
**Focus:** applied cryptography, threat modelling, browser storage, auditability.  
**Status:** functional prototype; not independently security-audited or certified.

### 🍽️ [CampusCanteen](https://github.com/manoj-9899/CampusCanteen)
A canteen pre-order and pickup workflow with student ordering, QR/token-based collection, staff queue management, inventory tools, and a simulated checkout flow.  
**Focus:** full-stack workflows, role-based access, database modelling, automated testing.  
**Demo:** [Open the deployed app](https://campusscanteen.netlify.app/)  
**Note:** payments are simulated; this is not a real payment service.

### ⌨️ [DevHabits](https://github.com/manoj-9899/devhabits)
A local-first developer habit tracker combining a terminal workflow with a web dashboard, analytics, keyboard-first interactions, and local persistence.  
**Focus:** developer tooling, CLI design, local-first software, UX.

### 🧭 [RepoPilot](https://github.com/manoj-9899/repopilot)
A repository-analysis MVP that inspects public GitHub repository metadata and approved text files, produces a readiness assessment, and drafts review-only patch plans.  
**Focus:** developer experience, repository diagnostics, AI-assisted workflows.  
**Boundary:** the current MVP is advisory and does not edit repositories or execute commands.

### 🤝 [SkillBridge](https://github.com/manoj-9899/SkillBridge)
A spec-driven concept for a local skill-exchange platform where people can trade skills and services without money.  
**Status:** early planning/specification stage; implementation is not complete.
